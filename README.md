## 🌌 What Is This?

> **NotesBackUp** is not a project — it's a *second brain*.
> A structured, tag-driven vault holding everything I learn about
> **programming, networking, databases, DevOps, and computer science**.

Every note lives where it *belongs* — not where it was *added*.
The vault is organized by **skill**, not by *session*.
