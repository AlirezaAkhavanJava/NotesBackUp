

**Definition:**  
**Interconnected** means that multiple devices or networks are **connected to each other so they can communicate or exchange data**.

The important part is **not just "connected"**, but **connected as part of a system of relationships**.

For example:

```text
PC A ───┐
        │
PC B ───┼── Switch ─── Router ─── Internet
        │
PC C ───┘
```

These devices are **interconnected** because they have network connections that allow them to communicate.

### In networking terminology

You can think of it as:

> **Network = a collection of interconnected devices.**

For example:

```text
Device
   ↓
Network
   ↓
Interconnected devices
   ↓
Communication
   ↓
Data exchange
```

### "Connected" vs "Interconnected"

- **Connected:** A → B
    
- **Interconnected:** A, B, C, D are connected through multiple links and can form a larger communication system.
    

For example, the Internet is often described as an **interconnected network of networks**:

```text
Home Network
     │
     ↓
 ISP Network
     │
     ↓
 ┌───┴────────┐
 ↓            ↓
Google       Cloudflare
Network      Network
 └──────┬─────┘
        ↓
   Other Networks
```

So when your networking material says **"interconnected devices"**, read it as:

> **Devices that are linked together in a network so they can communicate with one another.**
