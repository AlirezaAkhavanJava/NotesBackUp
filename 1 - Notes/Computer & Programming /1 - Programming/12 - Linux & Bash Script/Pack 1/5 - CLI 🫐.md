
A **CLI (Command-Line Interface)** is a way to interact with a computer **by typing text commands** instead of using a graphical interface (GUI).

---

### **1. Definition**

- CLI allows users to **control the operating system or software** by entering commands in text form.
    
- It is often provided through a **terminal or console**.
    

---

### **2. Key Features**

- **Text-based interaction** – no buttons or icons.
    
- **Powerful and precise** – can do things faster than GUI for many tasks.
    
- **Scripts and automation** – you can save sequences of commands as scripts.
    
- **Access to advanced features** – some OS features are only available via CLI.
    

---

### **3. Examples**

- **Unix/Linux CLI:** Bash, Zsh, Fish
    
- **Windows CLI:** Command Prompt (`cmd`), PowerShell
    
- Commands like:
    
    - `ls` → list files
        
    - `cd` → change directory
        
    - `mkdir` → make a folder
        
    - `grep` → search inside files
        

---

### **4. Quick Analogy**

CLI is like **talking directly to your computer in its language**. GUI is more like **using a remote control with buttons**.
