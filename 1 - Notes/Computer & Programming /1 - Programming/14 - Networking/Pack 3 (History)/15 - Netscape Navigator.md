## Netscape Navigator

**Netscape Navigator was a Web browser released in 1994 by Netscape Communications.** It became one of the most popular browsers of the early Web.

### Why was it created?

Mosaic had demonstrated that graphical Web browsers could make the Web mainstream.

**Marc Andreessen**, one of Mosaic's developers, left NCSA and co-founded Netscape Communications with **Jim Clark**.

They developed a new browser:

```text
NCSA Mosaic
     │
     │ Marc Andreessen
     ↓
Netscape Communications
     │
     ↓
Netscape Navigator
     │
     ↓
Mass adoption of the Web
```

### What did Navigator actually do?

Fundamentally, it was still a **Web client**:

```text
You type:
https://example.com
        │
        ▼
     URL parser
        │
        ▼
       DNS
        │
        ▼
      TCP/IP
        │
        ▼
       HTTP
        │
        ▼
    Web server
        │
        ▼
   HTML response
        │
        ▼
Netscape Navigator
        │
        ▼
    Rendered page
```

So Navigator wasn't a new Internet protocol. It was an **application using the existing Internet + Web protocols**.

---

## Why was Netscape so important?

It pushed the Web from:

**"Interesting technology" → "Something millions of people use."**

It supported increasingly sophisticated Web pages and helped establish the browser as the primary interface to the Internet for ordinary users.

And this led directly into one of the most important events in browser history:

```text
Mosaic
   ↓
Netscape Navigator
   ↓
Microsoft Internet Explorer
   ↓
Browser Wars
   ↓
Firefox / Safari / Chrome
```

### One important correction

People sometimes say:

> "Netscape invented the Web."

That's wrong.

The layers are:

|Technology|Main historical figure|
|---|---|
|Internet/internetworking|Vint Cerf, Bob Kahn and many others|
|DNS|Paul Mockapetris|
|World Wide Web|Tim Berners-Lee|
|Mosaic|Marc Andreessen, Eric Bina, NCSA team|
|Netscape Navigator|Netscape team, including Marc Andreessen|

**Netscape's role was commercialization and mass popularization of the Web**, not invention of the Web itself.
