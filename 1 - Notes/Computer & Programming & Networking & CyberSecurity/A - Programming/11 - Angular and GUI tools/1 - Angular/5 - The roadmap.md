
## The roadmap

**Phase 1: Foundations**

1. How a web app actually works (browser, HTML/CSS/JS, SPAs)
2. TypeScript for Java developers

**Phase 2: Core Angular**  
3. Components  
4. Templates and data binding  
5. Control flow and pipes (`@if`, `@for`, formatting)  
6. Component communication (`input`, `output`)  
7. Signals (Angular's reactivity)  
8. Services and dependency injection  
9. Routing

**Phase 3: Talking to the backend**  
10. Observables and RxJS basics  
11. HttpClient with Spring Boot  
12. Forms (template-driven vs reactive)  
13. Interceptors, guards, resolvers  
14. Authentication with Spring Security and JWT

**Phase 4: Advanced**  
15. Lifecycle hooks and change detection  
16. RxJS operators in depth  
17. State management  
18. Lazy loading and performance  
19. Testing  
20. Deployment with Spring Boot, plus large-scale architecture
