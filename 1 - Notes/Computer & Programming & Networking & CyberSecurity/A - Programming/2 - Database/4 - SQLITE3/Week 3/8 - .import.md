# SQLite `.import --csv --skip` — How It Works

The `.import` dot-command in the `sqlite3` CLI lets you bulk-load a CSV (or other delimited) file directly into a table. The syntax you're referring to is:

```
.import [OPTIONS] FILE TABLE
```

So:

```
.import --csv --skip 1 file.csv mytable
```

means:

| Piece | Meaning |
|---|---|
| `.import` | sqlite3 shell command (not SQL) |
| `--csv` | Parse the file as RFC 4180 CSV (quoted fields, embedded commas, `""` escapes) |
| `--skip 1` | Skip the first **1** line of the file before importing (commonly the header row) |
| `file.csv` | Path to the input file |
| `mytable` | Destination table name |

---

## Important behaviors

### 1. The header is *not* used automatically
`.import` never creates columns from the header row — it only writes values into an **existing** table. If you `--skip 1`, you're throwing the header away manually. If you don't skip, the header line becomes a data row (and usually errors or pollutes the table).

So you must create the table first:

```sql
CREATE TABLE mytable (id INTEGER, name TEXT, amount REAL);
.import --csv --skip 1 file.csv mytable
```

### 2. Table must exist (unless you're lazy)
In modern sqlite3 (3.32+), if the table **does not exist**, `.import` will create it using the first row of data — but then you do **not** want `--skip`, because the header row is what gets converted into column names:

```
.import --csv file.csv mytable      -- table created, header becomes columns
.import --csv --skip 1 file.csv mytable   -- table must already exist
```

### 3. `--skip` replaces the older `.mode` trick
Before this flag existed, people used `.mode csv` + `.import` and often `.once` or pre-processed the file to drop the header. `--skip N` is the modern, clean way (available since SQLite 3.32, 2020).

### 4. Other handy options
```
.import --csv --skip 2 --schema temp file.csv temp.tbl
```
- `--schema NAME` — target a schema other than `main` (e.g. `temp`).
- `--ascii` — old-style ASCII separator mode.
- `--skip N` — skip N lines from the top.
- You can also use `.import` with no flags after `.mode csv` for the same CSV effect.

### 5. Quoting in the shell
The whole thing is typed at the `sqlite3` prompt — no quotes needed around arguments unless the filename contains spaces:

```
.import --csv --skip 1 "my file.csv" mytable
```

---

## Typical full session

```
$ sqlite3 mydb.sqlite
sqlite> CREATE TABLE sales (date TEXT, region TEXT, amount REAL);
sqlite> .import --csv --skip 1 sales.csv sales
sqlite> SELECT COUNT(*) FROM sales;
```

That's the canonical use: pre-create the table with the schema you want, skip the CSV header, and import the rest.
