In **PostgreSQL (psql)**, you usually create an auto-incrementing primary key with either `SERIAL` (older style) or `GENERATED ... AS IDENTITY` (preferred in modern PostgreSQL).

Here are both ways:

### ✅ Modern way (`IDENTITY`, PostgreSQL 10+)

```sql
CREATE TABLE users (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL
);
```

- `BIGINT` (or `INT`) → numeric type for the id
    
- `GENERATED ALWAYS AS IDENTITY` → auto-incrementing
    
- `PRIMARY KEY` → makes it unique and indexed
    

If you want to be able to override the ID manually sometimes, use:

```sql
id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
```

---

### ✅ Older way (still works)

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name TEXT NOT NULL
);
```

- `SERIAL` is just shorthand for `INTEGER` + sequence + default value.
    

---

### Example insert

```sql
INSERT INTO users (name) VALUES ('Ethan');
INSERT INTO users (name) VALUES ('Alice');

SELECT * FROM users;
```

➡️ Output:

```
 id |  name
----+--------
  1 | Ethan
  2 | Alice
```
