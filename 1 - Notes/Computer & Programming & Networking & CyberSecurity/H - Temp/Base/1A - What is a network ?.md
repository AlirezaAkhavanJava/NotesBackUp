
## Definition
A **network** is a collection of two or more devices connected together so they can **communicate, share data, and share resources** using agreed-upon rules called **protocols**.

Examples of devices: computers, phones, servers, printers, routers, switches, IoT devices.

The **Internet** is a global network of networks.

## Core Components of a Network

| Component | Role |
|---|---|
| **End devices / nodes** | Devices that send or receive data, e.g. PC, phone, server. |
| **Intermediary devices** | Forward data, e.g. switches, routers, access points, firewalls. |
| **Communication links** | Carry signals, e.g. Ethernet cable, fiber, Wi-Fi, cellular. |
| **Protocols** | Rules for communication, e.g. TCP/IP, HTTP, DNS, Ethernet. |
| **Network software/services** | DNS, DHCP, routing protocols, security services. |

---

## How a Network Works

1. A device creates data, e.g. a file, web request, or email.
2. Data is broken into **packets**.
3. Each packet gets **addressing information**, such as source and destination IP/MAC addresses.
4. **Switches** forward frames within a local network using MAC addresses.
5. **Routers** forward packets between different networks using IP addresses.
6. The destination receives the packets, checks for errors, reorders them, and reassembles the original data.
7. Protocols ensure reliability, ordering, error detection, and security.

## Types of Networks

| Type | Meaning | Example |
|---|---|---|
| **PAN** | Personal Area Network | Bluetooth, phone to earbuds |
| **LAN** | Local Area Network | Home, office, school |
| **WLAN** | Wireless LAN | Wi-Fi network |
| **MAN** | Metropolitan Area Network | City-wide network |
| **WAN** | Wide Area Network | Internet, company across countries |
| **SAN** | Storage Area Network | Data center storage |
| **VPN** | Virtual Private Network | Secure tunnel over the Internet |

---

## Common Network Topologies

- **Star** – all devices connect to a central switch.
- **Bus** – all devices share one main cable.
- **Ring** – devices form a loop.
- **Mesh** – devices interconnect with many paths.
- **Hybrid** – combination of topologies.

---

## Why Networks Are Used

- Share files and printers
- Communicate via email, chat, voice, video
- Access the Internet
- Share storage and computing power
- Centralize management and backups
- Enable remote work, cloud services, and online gaming

---

## Challenges of Networks

- Security threats and attacks
- Congestion and latency
- Packet loss and jitter
- Hardware/software failures
- Cost and complexity of management
- Privacy and compliance

---

## In Short
A **network** is interconnected devices that exchange data using protocols. It uses packets, addresses, switches, and routers to move information. Networks range from small personal setups to the global Internet.
