# Linux Command Line Basics

The Linux command line is a text-based interface used to interact with the operating system. It allows users to execute commands, manage files, and automate tasks efficiently. Below is a list of common Linux commands and their functions.

## Commands

```bash
- `ls` --> Lists directory contents.
- `cd [directory]` --> Changes the current directory to the specified directory.
- `pwd` --> Prints the current working directory.
- `mkdir [directory]` --> Creates a new directory.
- `rm [file]` --> Removes a file.
- `rm -r [directory]` --> Removes a directory and its contents recursively.
- `cp [source] [destination]` --> Copies files or directories from source to destination.
- `mv [source] [destination]` --> Moves or renames files or directories.
- `touch [file]` --> Creates an empty file or updates the timestamp of an existing file.
- `cat [file]` --> Displays the contents of a file.
- `less [file]` --> Views file contents one page at a time.
- `head [file]` --> Displays the first 10 lines of a file.
- `tail [file]` --> Displays the last 10 lines of a file.
- `grep [pattern] [file]` --> Searches for a pattern in a file.
- `find [path] -name [file]` --> Searches for files by name in the specified path.
- `chmod [permissions] [file]` --> Changes file permissions.
- `chown [user] [file]` --> Changes file ownership.
- `man [command]` --> Displays the manual page for a command.
- `ps` --> Lists running processes.
- `kill [pid]` --> Terminates a process by its process ID.
- `top` --> Displays real-time system processes and resource usage.
- `df -h` --> Shows disk space usage in a human-readable format.
- `du -h [directory]` --> Displays disk usage of files and directories.
- `tar -cvf [archive.tar] [files]` --> Creates a tar archive.
- `tar -xvf [archive.tar]` --> Extracts a tar archive.
- `wget [url]` --> Downloads files from the web.
- `curl [url]` --> Transfers data from or to a server.
- `sudo [command]` --> Executes a command with superuser privileges.
- `apt-get install [package]` --> Installs a package (Debian-based systems).
- `yum install [package]` --> Installs a package (Red Hat-based systems).
- `whoami` --> Displays the current user's username.
- `passwd` --> Changes the user's password.
- `reboot` --> Restarts the system.
- `shutdown -h now` --> Shuts down the system immediately.

```
