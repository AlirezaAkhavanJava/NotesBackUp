
In computing, a **file** is a **container for storing data** on a storage device like a hard drive, SSD, or USB.

---

### **1. Definition**

- A file can contain **text, images, videos, programs, or any kind of digital data**.
    
- Files have **names** and are stored in **directories/folders**.
    

---

### **2. Components of a File**

1. **Filename** – the name you use to reference it (`report.txt`).
    
2. **Extension** – indicates file type (`.txt`, `.jpg`, `.mp4`).
    
3. **Content** – the actual data inside the file.
    
4. **Metadata** – information about the file, like:
    
    - Size
        
    - Creation/modification date
        
    - Permissions (who can read/write/execute)
        

---

### **3. Types of Files**

- **Text files** → contain readable characters (`.txt`, `.csv`)
    
- **Binary files** → not directly readable (`.exe`, `.jpg`, `.mp3`)
    
- **System files** → used by OS (`/etc/passwd`, `/bin/bash`)
    

---

### **4. File Operations (Common in Unix/Linux)**

- `ls` → list files
    
- `cp` → copy files
    
- `mv` → move/rename files
    
- `rm` → delete files
    
- `cat` → view file contents
    
- `touch` → create an empty file
    

---

### **5. Quick Analogy**

A file is like a **physical folder or notebook**:

- The **name** is the label,
    
- The **content** is what’s inside,
    
- **Metadata** is like a sticker saying “Created on Jan 1, owned by Ethan”.
