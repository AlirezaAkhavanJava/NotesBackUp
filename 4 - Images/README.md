## 📖 About This Repository

This repository is a note vault rather than an application project. It stores organized markdown notes and supporting materials for learning and personal knowledge management.

The structure is intentionally split into folders for:

- notes content
- tags
- dashboard/planning files
- images
- worksheet material
- Obsidian-specific settings

```text
├── 5 - Worksheet/

```

### Folder overview

- `.obsidian/` — Obsidian workspace settings and local vault metadata
- `1 - Notes/` — main knowledge base and learning notes
- `2 - Tags/` — tag-related organization files
- `3 - Dash/` — dashboard or index files
- `4 - Images/` — images and visual assets used in notes
- `5 - Worksheet/` — practice, exercises, and working notes

---

## 🧭 How to Use

```bash
git clone https://github.com/AlirezaAkhavanJava/NotesBackUp.git
cd NotesBackUp
```

Then open the vault in Obsidian or browse the folders directly:

- `1 - Notes/` for main content
- `2 - Tags/` for tag organization
- `3 - Dash/` for overview/dashboard files
- `4 - Images/` for attached media
- `5 - Worksheet/` for active learning notes
