

**React** is a JavaScript library used to build **user interfaces**, especially interactive websites and web applications.

It helps you create a UI from reusable pieces called **components**. For example:

```jsx
function Welcome() {
  return <h1>Hello, world!</h1>;
}

export default Welcome;
```

Here, `Welcome` is a React component.

A simple way to think about it is:

**HTML** → structure  
**CSS** → appearance  
**JavaScript** → behavior  
**React** → organizes the UI into reusable, interactive components

React is commonly used for things like dashboards, e-commerce sites, social-media interfaces, and other web apps where the page changes based on user interaction.
